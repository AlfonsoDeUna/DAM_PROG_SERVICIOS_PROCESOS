6. Declaración de métodos

Ejemplo del profesor

Nuestra clase Alumno incorpora ahora dos métodos.

Python
class Alumno:
    nombre: str
    edad: int
    dni: str

    def __init__(self, nombre, edad, dni):
        self.nombre = nombre
        self.edad = edad
        self.dni = dni

    def presentarse(self):
        print(f"Me llamo {self.nombre}")
        print(f"Tengo {self.edad} años")

    def cumplir_anios(self):
        self.edad += 1
