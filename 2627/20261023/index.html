Ir a la prueba
¿Es tu primera vez? Así se trabaja aquí+

Vas a usar dos ventanas: esta web te guía y tu editor ejecuta Python. Una misión es una actividad con una prueba inicial y un cambio para comparar.

  1. Lee y sitúateEntiende qué recibe el programa, qué hace y qué debería mostrar. Debajo tienes el código o el encargo para escribirlo.
  2. Prepara la primera pruebaCrea el archivo indicado, guarda una predicción y ejecuta el comando en la terminal. Una predicción es lo que crees que ocurrirá y por qué; puede ser incorrecta.
  3. Comprueba y experimentaPega el texto que imprime Python en «Prueba inicial». Cuando coincida, se abrirá el cambio del experimento. Guarda, ejecuta otra vez y comprueba la nueva salida.
  4. Explica y conservaResponde «Comprobar mi idea» y escribe tu descubrimiento. Los intentos quedan en «Mi cuaderno», que descargarás para entregar.

Para preparar el archivo: abre una carpeta en VS Code, crea un archivo con el nombre de esta misión y guárdalo. En Terminal → Nueva terminal, escribe el comando que aparece debajo del programa y pulsa Intro. La terminal debe estar en esa misma carpeta.

La web no ejecuta el código Python. Si ves >>>, estás dentro del intérprete de Python: escribe exit() para volver a la terminal y ejecutar el archivo completo.
